# HR Policy RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers questions from an HR Policy document.

## Technologies Used

- Python
- Jupyter Notebook
- Sentence Transformers
- FAISS
- RAG

## Project Overview

This project converts an HR policy document into chunks, generates embeddings, stores them in a vector database, and retrieves relevant information to answer user queries.

## Project Workflow

HR Policy Document
→ Text Chunking
→ Embeddings
→ FAISS Vector Store
→ Similarity Search
→ Relevant Context
→ Answer
